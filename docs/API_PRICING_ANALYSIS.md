# API課金分析：1日4回のデータ更新について

## 概要

現在のスケジューラー設定は**1日4回（深夜1時、朝7時、昼13時、夜19時 JST）**です。この設定での課金影響を分析します。

## 使用している外部APIと課金体系

### 1. YouTube Data API v3
- **無料クォータ**: 10,000 units/日
- **1回のリクエスト**: 約100-200 units（`search.list`で100 units、`videos.list`で1 unit）
- **1日4回更新**: 約400-800 units/日
- **課金**: **無料枠内** ✅
- **備考**: 無料枠を超えても課金なし（ただし追加クォータの申請が必要）

### 2. Listen Notes API (Podcast)
- **無料プラン**: 300 requests/月
- **1回のリクエスト**: 1 request
- **1日4回更新**: 120 requests/月（30日 × 4回）
- **課金**: **無料枠内** ✅
- **備考**: 月間300リクエスト以内なら無料

### 3. Spotify Web API
- **無料**: 完全無料
- **レート制限**: 10 requests/秒（開発モード）
- **1日4回更新**: 問題なし
- **課金**: **無料** ✅

### 4. News API
- **無料プラン**: 100 requests/日
- **1回のリクエスト**: 1 request
- **1日4回更新**: 4 requests/日
- **課金**: **無料枠内** ✅

### 5. World News API
- **無料プラン**: 50 points/日
- **1回のリクエスト**: 約1-2 points（結果数による）
- **1日4回更新**: 約4-8 points/日
- **課金**: **無料枠内** ✅

### 6. Twitch API
- **無料**: 完全無料
- **レート制限**: 800 points/分
- **1日4回更新**: 問題なし
- **課金**: **無料** ✅

### 7. 楽天API
- **無料**: アフィリエイトプログラム経由で無料
- **レート制限**: 特に制限なし（適切な使用が前提）
- **1日4回更新**: 問題なし
- **課金**: **無料** ✅

### 8. Google Trends (BigQuery)
- **無料**: Google Cloud の無料枠内
- **BigQuery**: 月間1TBのクエリが無料
- **1日4回更新**: 問題なし
- **課金**: **無料枠内** ✅

### 9. Reddit API

### 11. Hacker News API

### 12. Product Hunt API

## インフラコスト

### Fly.io PostgreSQL
- **無料枠**: 3GBの永続ストレージ
- **1日4回更新**: データ量は変わらない（キャッシュの上書き）
- **課金**: **無料枠内** ✅

### Fly.io アプリケーション
- **無料枠**: 3つのshared-cpu-1x 256MB VM
- **1日4回更新**: CPU/メモリ使用量はほぼ同じ
- **課金**: **無料枠内** ✅

## 結論

### ✅ **1日4回のデータ更新でも課金は発生しません**

**理由**:
1. **すべてのAPIが無料枠内**: 1日4回更新でも、すべてのAPIの無料枠内に収まります
2. **インフラコスト**: Fly.ioの無料枠で十分です
3. **データ量**: キャッシュの上書きなので、ストレージ使用量は変わりません

### 注意点

1. **Listen Notes API**: 月間300リクエストの制限があるため、1日4回更新（120回/月）でも余裕があります
2. **YouTube API**: 1日10,000 unitsの制限があり、1日4回更新（約400-800 units）でも十分余裕があります
3. **World News API**: 1日50 pointsの制限があり、1日4回更新（約4-8 points）でも十分余裕があります

### 現在の設定

現在のスケジューラー設定：
- **実行時刻**: 深夜1時、朝7時、昼13時、夜19時（日本時間）
- **更新頻度**: 1日4回

スケジューラーの設定は `services/scheduler/scheduler_manager.py` で確認・変更できます。
