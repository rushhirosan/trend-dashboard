## いまの週次との差

いまの `generate_ai_weekly_summary.py` は、ブリーフの本文だけを作る。note と Substack の記事は作らない。

| | ブリーフ（いまの週次メール） | note / Substack |
|---|------------------------|----------------|
| 中身 | マーケット、流れ、動いた話題、ホット最大5、カテゴリ top3 | 2日以上残ったホット上位3つだけ |
| コメント | 書かない | 同じ週の公開記事に書いてあることだけ |
| 末尾 | サイト誘導は付けない | ダッシュボードと、メールとの差分 |
| 配信 | 月曜 7:30 生成、メールは 10:00 頃 | 月曜 8:00 頃に貼る。未実装 |

貼る文の見本: [`note_template.md`](note_template.md)（日本語）、[`substack_template.md`](substack_template.md)（英語）。どちらも 2026-W40。

ニュース区分の1位が週の顔に見えるのは、見出しが日ごとに別ラベルになり、流れの文がニュース枠の先頭から取るため。週全体のホット1位とは別である。

## 共通

- 対象週は、直前に終わった月曜〜日曜（JST）。日曜を閉じる 01 スロットは月曜 1:00。
- 地域は分ける。日本語は日本向け系列、英語は米国向け系列。
- 人が本文を書かない。
- 課金は Gumroad の月額メンバーシップ（日本は月額300円、米国は月額2ドル）。note の有料マガジンや Substack の有料購読にはしない。

## 週次ブリーフ

購読者向けのメール。ダッシュボードを知っている人に、閉じた週を1枚で渡す。

実装済み。出力は `weekly/YYYY-Www.md`（jp）と `weekly/us/YYYY-Www.md`（us）。メール実着は月曜 10:00 頃。

本文はこの順。

1. 先週のマーケット（為替・株）。カレンダーとひと息は出さない。
2. 先週の流れ（順位の動きが最大の1件と、カテゴリ上位）。1日だけの見出しも入る。
3. いちばん動いた話題（週内ジャンプ。App Store は除く）。
4. ホットトピック（最大5件。1日だけのものも含む。App Store と、週の大半で居座る暗号資産・ほぼ全日の株は除く）。
5. カテゴリ別の先週の top3（1日だけの話題も含む）。

「来週に残る論点」は書かない。末尾にダッシュボードや Gumroad は付けない。理由の段落も、前週からの継続の文も付けない。

## note

ダッシュボードを知らない人向けの無料記事。日本語。個人の note とは別アカウント。有料マガジンにはしない。支払いは記事の中では受けない。

未実装。公開の目標は月曜 8:00 頃。見本は [`note_template.md`](note_template.md)。

本文はこの順。

1. タイトルは「先週のホットトピック3つ」。
2. 対象週と、2日以上残った上位3つであること。順位は観測結果。コメントは同じ週の公開記事に書いてあることだけ、と書く。
3. ホット上位3件。選び方はブリーフのホットと同じスコア（出現日数×10 + 複数ソース +15 + 系列重み）で、1日だけのもの、App Store、居座る暗号資産・ほぼ全日の株を除いた先頭から3件。各件は、出ていた日の順位と、同じ週の公開記事。理由が観測結果に無いときは「今回の観測結果では出てきません」。材料が複数あるときは、どれが順位の理由かは記載しない。
4. 末尾は、カテゴリごとの順位と日毎の観測結果は入れていないこと。ダッシュボードは `https://trends-dashboard.com`。メールにサブスクライブすると毎朝の日次と、月曜の週次（カテゴリ別 top3）が届くこと。時刻の目標は日次 9:00 頃、週次は月曜 10:00 頃。

週次ブリーフの一覧は貼らない。2日以上のホットが3件無い週は、ある件数だけ書く。0件の週は記事を出さない。

## この仕様ではやらない

- note や Substack に、週次ブリーフの一覧を貼る
- ニュース1位を、note や Substack の先頭にする
- タイトルだけをモデルに渡して、話題になった理由を書かせる
- 公開記事に無い原因や、観測結果に無い理由を書く
- note と Substack で構成を変える
- ブリーフのメールに、note 用のコメントを足す
- 記事内に Gumroad のリンクを置く
