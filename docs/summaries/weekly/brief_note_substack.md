# 週次の出し方（ブリーフ / note / Substack）

親: [`weekly/README.md`](README.md)

ブリーフは実装済み。note と Substack は未実装。

## いまの週次との差

いまの `generate_ai_weekly_summary.py` は、ブリーフの本文だけを作る。note と Substack の記事は作らない。

| | ブリーフ（いまの週次） | この仕様の note / Substack |
|---|------------------------|----------------------------|
| 先頭 | 先週のマーケット | 2日以上出たホット1位を1件、深く書く |
| 1日だけの話題 | 流れ・ホット・カテゴリに入る | 先頭には使わない。後半のブリーフには残る |
| 「なぜ話題になったか」 | 無い | URL の説明が取れたときだけ、先頭の1件に書く |
| 前週からの継続 | 無い | ホット1位が前週と同じときだけ1文 |
| 末尾 | サイト誘導は付けない | ダッシュボード、その次に Gumroad |
| 配信 | 月曜 7:30 生成、メールは 10:00 頃 | 月曜 8:00 頃に貼る。未実装 |

ニュース区分の1位が週の顔に見えるのは、見出しが日ごとに別ラベルになり、流れの文がニュース枠の先頭から取るため。週全体のホット1位とは別である。

## 共通

- 対象週は、直前に終わった月曜〜日曜（JST）。日曜を閉じる 01 スロットは月曜 1:00。
- 地域は分ける。日本語は日本向け系列、英語は米国向け系列。
- 人が本文を書かない。
- 課金は Gumroad の月額メンバーシップ（日本は月額300円、米国は月額2ドル）。note の有料マガジンや Substack の有料購読にはしない。

## 週次ブリーフ

購読者向けのメール。ダッシュボードを知っている人に、閉じた週を1枚で渡す。

実装済み。出力は `weekly/YYYY-Www.md`（jp）と `weekly/us/YYYY-Www.md`（us）。メール実着は月曜 10:00 頃。

本文はこの順。

1. 先週のマーケット（為替・株）。カレンダーとひと息は出さない。
2. 先週の流れ（順位の動きが最大の1件と、カテゴリ上位）。1日だけの見出しも入る。
3. いちばん動いた話題（週内ジャンプ。App Store は除く）。
4. ホットトピック（最大5件。1日だけのものも含む。App Store と、週の大半で居座る暗号資産・ほぼ全日の株は除く）。
5. カテゴリ別の先週の top3（1日だけの話題も含む）。

「来週に残る論点」は書かない。末尾にダッシュボードや Gumroad は付けない。理由の段落も、前週からの継続の文も付けない。

## note

ダッシュボードを知らない人向けの無料記事。日本語。支払いは記事の中では受けない。

未実装。公開の目標は月曜 8:00 頃。生成ブロックをそのまま貼る。8:00 に間に合わせるなら、メール（10:00 頃）より前にブロックが出来ている必要がある。

本文はこの順。

1. その週のホット1位を1件。出現が2日以上のものだけ。選び方はブリーフのホットと同じスコア（出現日数×10 + 複数ソース +15 + 系列重み）で、1日だけのもの、App Store、居座る暗号資産・ほぼ全日の株を除いた先頭。
2. その1件について、機械で次を書く。何日出ていたか、最高順位、欠けている日、出ていた各日の 07時 → 13時 → 19時。
3. 「なぜ話題になったか」は、その URL から説明文が取れたときだけ。モデルは `gpt-4o-mini`（`OPENAI_SUMMARY_MODEL`）。週に1回、数文。渡す材料は説明文と順位だけ。説明に無い原因や予測は書かない。YouTube、検索URL、取得失敗のときはこの段落を出さない。
4. 前週の note のホット1位とラベルが同じときだけ、「先週から続いている」を1文足す。モデルは使わない。
5. 上の週次ブリーフ（jp）を、そのまま続ける。
6. 末尾はダッシュボード（`utm_source=note`、`utm_medium=weekly`）、その次に JP の Gumroad。

2日以上のホットが無い週は、1〜4 を出さない。ブリーフと末尾リンクだけにする。

## Substack

ダッシュボードを知らない人向けの無料記事。英語。作りは note と同じ。

未実装。公開の目標は月曜 8:00 頃。

本文はこの順。

1. 米国向けのホット1位を1件。2日以上。除き方は note と同じ。
2. その1件の順位（日数、最高順位、欠けた日、各日の 07時 → 13時 → 19時）。
3. 「なぜ」は、説明文が取れたときだけ `gpt-4o-mini` で数文。取れなければ出さない。
4. 前週の Substack のホット1位と同じラベルのときだけ、継続の1文。
5. 週次ブリーフ（us）を、そのまま続ける。
6. 末尾は US のダッシュボード（`utm_source=substack`、`utm_medium=weekly`）、その次に US の Gumroad。

2日以上のホットが無い週は、1〜4 を出さない。

## この仕様ではやらない

- ブリーフの本文から、1日だけの話題やカテゴリ top3 を外す
- ニュース1位を、note や Substack の先頭にする
- タイトルだけをモデルに渡して、話題になった理由を書かせる
- note と Substack で構成を変える
- ブリーフのメールに、note 用の「なぜ」を足す
