# 週1回 · 1ツイート（ウィークリー振り返り）

## テンプレート（コピペ用）

```
【今週の振り返り YYYY-MM-DD〜YYYY-MM-DD】
JPよく出た: ○○ / ○○ / ○○
USよく出た: ○○ / ○○ / ○○
今週の印象: （1行だけ）
一覧: https://trends-dashboard.fly.dev/
```

---

## 運用のコツ

- **曜日は固定**（例: 日曜20時＝週の締め、月曜20時＝週の地図）どちらか。
- 「よく出た」は厳密な集計でなく、**その週のデイリーで繰り返し見えたキーワード**でよい。
- 印象1行が週次の価値の核。

---

## 埋め例（実データではないダミー）

```
【今週の振り返り 2026-05-01〜2026-05-07】
JPよく出た: 人事・行政ニュース / 株安・円相場 / 連休レジャー
USよく出た: BigTech・AI / 金利・インフレ指標 / 映画・シリーズ新作
今週の印象: JPはマクロと国内イベント、USはテック決算と金融が並んで動いた週
一覧: https://trends-dashboard.fly.dev/
```
