What is this site?

This site is a simple trends dashboard that shows what is currently popular in Japan and the US.

What data does it use?

It aggregates public data from sources such as:

  • Google Trends
  • YouTube
  • GitHub
  • News and media RSS feeds
  • Security trends (CISA, IPA, JPCERT/CC)
  • App Store / Play Store
  • Stock and Cryptocurrency markets

The data is updated twice a day (7 AM and 2 PM JST).

How should I use it?

This trends dashboard is intended for quick discovery and overview. It does not aim to provide exhaustive or real-time data.

About the creator

This is an independent personal project. If you find it useful, feedback or support is always welcome.
