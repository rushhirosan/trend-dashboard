About Trends Dashboard

Trends Dashboard is a free web app that displays the latest trend information from the US in one place. You can see keywords and content that are trending across multiple services on a single screen.

Features

  • Display trends from Google Trends, YouTube, Spotify, Hacker News, Twitch, Podcasts and more
  • Tech platform trends: Product Hunt, DEV.to, Medium, GitHub
  • Stock and cryptocurrency market trends
  • News trends from CNN, World News, The Hacker News

Data Update

Data update processing starts daily at 1 AM, 7 AM, 1 PM, and 7 PM (JST). It may take 10-20 minutes to complete. Check the Data Freshness page for the latest status.
